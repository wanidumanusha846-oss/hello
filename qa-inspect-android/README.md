# QA Inspect - Android APK

## Get the APK (about 5 minutes, free)
1. Create a free account at https://github.com and make a new repository (Private is fine).
2. Click "uploading an existing file" and drag in EVERYTHING from this folder.
   Keep the .github folder (if your computer hides it, show hidden files).
3. Commit. Open the Actions tab: "Build Android APK" runs automatically (3-6 min).
4. Open the finished run, go to Artifacts, download QA-Inspect-APK, unzip to get app-debug.apk.
5. Send the APK to the phone, open it, allow "Install unknown apps", install.

## Changing links later
Edit www/index.html (the SECTIONS block), commit, and download the new APK from Actions.
Cutting, Molding and Packing still contain PASTE_ placeholder links.
